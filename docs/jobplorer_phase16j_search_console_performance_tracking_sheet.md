# Jobplorer Phase 16J Search Console Performance Tracking Sheet

## Purpose

Phase 16J creates an owner-fillable Google Search Console Performance tracking sheet for indexed Jobplorer URLs.

This phase is docs-only. It does not modify content, posts, config, CNAME, layouts, themes, generated output, job-site pages, country guides, or career guides.

## Decision Rules

- If impressions are 0 or very low, monitor only.
- If a URL is indexed with meaningful impressions but low CTR, consider title/meta review later.
- If traffic drops after a rewrite, hold additional legacy rewrites until the pattern is understood.
- Do not change URLs, slugs, canonicals, `noindex`, sitemap behavior, redirects, or filenames based only on early data.
- Do not over-optimize titles from a small sample.
- Do not make legal, salary, visa, labor, tax, hiring, guarantee, ranking, affiliate, or partnership claims during any future content review.
- Treat Search Console data as directional, especially during the first weeks after setup and indexing requests.
