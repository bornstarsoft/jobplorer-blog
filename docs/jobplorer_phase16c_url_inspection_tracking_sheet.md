# Jobplorer Phase 16C URL Inspection Tracking Sheet

## Purpose

Phase 16C creates an owner-fillable URL Inspection tracking sheet for important Jobplorer URLs after Google Search Console domain verification and sitemap submission.

## Decision Rules

- If a URL is on Google and the Google-selected canonical is correct, monitor.
- If a URL is not indexed, request indexing and monitor.
- If the Google-selected canonical differs from the intended URL, investigate before changing content.
- If a crawl or index warning appears, document the warning before editing source files.
- Do not delete, noindex, rename, move, or rewrite based only on one early URL Inspection result.
- Do not make slug, filename, canonical, sitemap, or redirect changes without a separate approved plan.
