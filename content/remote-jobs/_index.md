# Remote Jobs

Start with the kind of work you want to do, then check where and how the employer expects it to be done. A remote search result is a lead to investigate.

## Start With the Remote Work Guide

The [Remote Workers guide](/career-guides/remote-workers/) includes a posting checklist for location, time zones, office attendance, and communication expectations.

## Build a Focused Shortlist

1. Choose a role family, such as [software development](/career-guides/software-developers/) or [game development](/career-guides/game-developers/).
2. Compare current postings through [LinkedIn](/job-sites/sites/linkedin/), [Indeed](/job-sites/sites/indeed/), and employer career pages.
3. Record the work arrangement exactly as stated. Keep unclear details as questions for the employer.
4. Re-check the original posting before applying, using the [application record template](/job-seeker-tools/#application-record-template).

Jobplorer does not host live remote vacancies or provide employment, tax, visa, or legal advice. Employer instructions and current postings remain the source for application details.
